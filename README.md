# Ai_Battlefield_Survilance_System
Made Deep Learning project using the YOLO11 Pipeline which helps us for safety object detection with human in the loop. i have used Computer Vision. Made my own Arms Dataset for the same.
## Dataset

The model was trained on the **gundataset**, which contains weapon detection imagery. 
You can view and download the dataset from Kaggle here: 
[gundataset by Yadav Dev Dayanand](https://www.kaggle.com/datasets/yadavdevdayanand/gundataset)
kaggle.com/datasets/rawsi18/military-assets-dataset-12-classes-yolo8-format
